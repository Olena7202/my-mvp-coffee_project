# CoffeeHouse ☕️

React + Vite проєкт для кавового сайту з каталогом, кошиком та промо‑секціями.

## 📌 Що ми зробили

- **Hero секція**  
  Головний банер із заголовком *«Смак, який пробуджує ранок»* та двома кнопками:
  - «Переглянути каталог»
  - «Кава дня» (випадковий продукт)

- **Кава дня (RandomCoffee)**  
  Компонент, який показує випадковий продукт одразу при завантаженні сторінки.  
  Кнопка «Кава дня» дозволяє оновити продукт на інший випадковий.

- **Топові пропозиції (ProductList + ProductCard)**  
  Список продуктів із картками:
  - Фото кави
  - Назва, опис, ціна
  - Кнопка «Додати в кошик» (стилізована у преміум‑стилі)

- **WhyUs секція**  
  Блок «Чому обирають нас» із трьома перевагами:
  - Свіже обсмаження
  - Швидка доставка
  - Натуральні зерна  
  Стилізовано у темному фоні з золотистими акцентами.

- **Каталог (CatalogPage)**  
  Сторінка з усіма продуктами у вигляді акуратної сітки.  
  Картки вирівняні: однакова висота зображень, текст, ціна та кнопка на одному рівні.

- **Кошик (CartPage)**  
  Сторінка з товарами, які користувач додав:
  - Картка товару з фото, ціною та кількістю
  - Кнопки `+ / - / Видалити`
  - Підсумок із загальною сумою
  - Кнопка «Оформити замовлення»

## 🛠️ Технології

- **React + Vite** — швидкий фронтенд‑фреймворк
- **CSS (custom styles)** — адаптивний дизайн, преміум‑стиль із золотистими акцентами
- **Компонентний підхід** — кожен блок сайту реалізований як окремий компонент
